# 科高樱花社 · 网站更新日志

> 记录网站的迭代过程

## 2026-11-07
**新增日志与分享优化**
- 新增此更新日志页面。
- 全站页面加入 Open Graph 协议，优化 QQ/微信 的链接卡片分享效果。

## 2026-11-06
**音乐播放器重构**
- 升级为可折叠式悬浮播放器，并加入右侧设置面板。
- 歌单数据抽离为 JSON，支持网易云外链播放。
- 新增浏览器本地缓存（Service Worker）管理功能，大幅提升二次访问速度。

## 2026-11-05
**核心服务迁移**
- 原 Supabase 因闲置被停用，导致数据丢失。
- 排行榜迁移至 Appwrite Cloud，确保长期免费无闲置暂停风险。
- 留言板迁移至 Giscus，基于 GitHub Discussions，免去自建后端。
- 修复并优化排行榜的响应式排版与 GitHub 头像获取逻辑。

## 2026-10-30
**服务异常**
- 因闲置时间过长，Supabase 免费版自动暂停了排行榜与留言板服务。

## 2026-10-18
**样式重构与内容扩充**
- 网站视觉全面重构，切换为复古羊皮纸亮色主题与像素字体。
- 优化宽屏（PC）与竖屏（手机）下的响应式排版。
- 相关页面新增 10 个科高 ACGN 相关友群信息。

## 2026-10-02
**题库升级**
- 新增近 600 道题库。
- 原有题库划分为「简单模式」，新题库划分为「困难模式」。

## 2026-10-01
**网站第一版发布**
- 确立初期视觉样式。
- 上线社史时间线（由 Cyan. 提供资料）。
- 上线 ACGN 小测（普通/无尽模式）。
- 上线相关链接（科外所、贴吧、微博等）。
- 上线留言板（基于 Supabase，支持 GitHub 登录）。
